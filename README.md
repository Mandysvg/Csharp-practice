## what i have learned
- Namespace: Namespace is a way to organize code. It is a container for classes and other namespaces.
- Using system, means we can use classes from the System namespace. System is a namespace, console is a class from the system namespace and writeline is a method.
- Class: A class is a container for data and methods, which bring functionality to your code. Every code in C# that will run must be in a class.
- In this program Program is the name of our class
- Every C# statement ends with a semicolon;
- C# is case sensitive
- For better organization we can match the C# file name to the class name
